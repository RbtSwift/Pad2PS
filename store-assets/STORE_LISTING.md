## Português (Brasil)

### App name
`Pad2PS - Guia de Controle`

### Subtitle
`Guia visual de controles, layouts e diagnóstico`

### Full description
Pad2PS é um guia visual multiplataforma para quem quer consultar, testar e entender controles de videogame no computador e em dispositivos móveis.

Consulte layouts interativos de PlayStation, Xbox, Nintendo Switch e outros controles. Identifique entradas em tempo real, visualize vibração e gatilhos, confira a taxa de atualização e a latência, diagnósticos de drift e circularidade e inspecione dados brutos de hardware.

Recursos principais:
- Layouts visuais interativos para diferentes controles
- Diagnóstico em tempo real de sticks, gatilhos, polling rate e bouncing
- Monitoramento de bateria integrado
- Sequências de comandos e treinador de combos
- Exportação de diagramas e sequências
- Banco SDL GameControllerDB integrado para identificação offline
- Interface adaptável para celulares, tablets e desktop
- Janela Picture-in-Picture sempre no topo no Desktop

Pad2PS é gratuito e não contém anúncios. O app não usa telemetria e, para suas funções principais, mantém os dados de controle e calibração no próprio dispositivo. Não é o Pad2PS Launcher: este aplicativo é um guia e diagnóstico de controles, não um organizador ou iniciador de jogos.

O formulário opcional de contato pode enviar nome, e-mail, assunto e mensagem pelo Web3Forms somente quando o usuário escolhe usá-lo. O envio não é necessário para usar o aplicativo.

Suporte: contato@pad2ps.com.br

## United States English

### App name
`Pad2PS - Controller Guide`

### Subtitle
`Visual controller layouts, testing and diagnostics`

### Full description
Pad2PS is a cross-platform visual guide for consulting, testing and understanding game controllers on computers and mobile devices.

Browse interactive layouts for PlayStation, Xbox, Nintendo Switch and other controllers. Identify inputs in real time, inspect vibration and triggers, check polling rate and latency, diagnose stick drift and circularity, and view raw hardware data.

Key features:
- Interactive visual layouts for different controllers
- Real-time stick, trigger, polling-rate and bouncing diagnostics
- Integrated battery monitoring
- Command sequences and combo trainer
- Diagram and sequence export
- Bundled SDL GameControllerDB for offline controller identification
- Responsive interface for phones, tablets and desktop
- Always-on-top Picture-in-Picture window on Desktop

Pad2PS is free and contains no ads. The app does not use telemetry, and core controller and calibration data stays on the user's device. This is not Pad2PS Launcher: Pad2PS is a controller guide and diagnostic tool, not a game library organizer or launcher.

The optional contact form may send a name, email address, subject and message through Web3Forms only when the user chooses to use it. Submission is not required to use the app.

Support: contato@pad2ps.com.br

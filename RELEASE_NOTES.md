## Português (Brasil)

- Adiciona uma seção integrada "Sobre & Legal" ao painel de ajustes, com privacidade, termos, suporte e comunidade.
- Mantém os atalhos oficiais para site, e-mail, GitHub Issues, Discord e redes sociais no visual nativo do app.
- Publica changelogs no formato Debian no repositório APT para aparecer no Atualizador de Programas do Zorin OS e Ubuntu.
- Atualiza o Desktop e o Android para a versão 1.0.6.
- Redesenha a interface Android para smartphones e tablets, com layout em uma coluna no retrato e duas colunas em telas largas ou no modo paisagem.
- Organiza o cabeçalho, o seletor de layouts, o diagrama interativo do controle, a telemetria e os atalhos para referência e métricas.
- Adiciona navegação inferior que respeita as áreas seguras do Android e reúne tema, idioma, som e deadzone em uma gaveta de configurações.
- Remove o Picture-in-Picture do Android; o recurso continua disponível no Desktop.
- Atualiza a identificação offline de controles com o banco SDL GameControllerDB integrado ao app.

## English

- Adds an integrated "About & Legal" section to the settings panel with privacy, terms, support, and community links.
- Keeps official shortcuts to the website, email, GitHub Issues, Discord, and social networks consistent with the app's native visual style.
- Publishes Debian-formatted changelogs in the APT repository for Zorin OS and Ubuntu Software Updater.
- Updates Desktop and Android to version 1.0.6.
- Redesigns the Android interface for phones and tablets, using one column in portrait and two columns on wide screens or in landscape.
- Organizes the header, layout selector, interactive controller diagram, telemetry, and shortcuts to reference and metrics.
- Adds bottom navigation that respects Android safe areas and groups theme, language, sound, and deadzone controls in a settings drawer.
- Removes Picture-in-Picture from Android; the feature remains available on Desktop.
- Updates offline controller identification with the SDL GameControllerDB bundled in the app.
